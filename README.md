# 和風の部屋からの脱出

ブラウザで遊べる脱出ゲーム。畳の和室をタップ（クリック）で探索し、アイテムと暗号の手がかりを集めて脱出を目指す。

## 遊び方

- `index.html` をブラウザで開くだけで遊べる（単一ファイル、サーバー不要）
- 部屋の各所をタップして調べる。アイテムは持ち物欄から選択して使う
- 詰まったらヒントボタン（段階的に詳しくなる）
