# 仕様書：和風の部屋からの脱出

## 概要

- ジャンル：ポイント＆クリック型 脱出ゲーム
- プラットフォーム：ブラウザ（スマホ／PC両対応、単一HTMLファイル）
- プレイ時間目安：5〜10分

## 舞台

畳・床の間・箪笥・行灯のある和室。出口の戸が施錠されている。

## 謎解きの流れ（3段）

1. 座布団をめくる → **真鍮の小鍵**を入手
2. 小鍵で箪笥の下段を開ける → メモを入手。掛け軸の四季の花（春・夏・秋・冬）の数が4桁ダイヤルの答え
3. ダイヤル錠の小箱を開ける → **鉄の鍵**を入手 → 出口の戸を開けて脱出

## 機能

- タイマー（クリアタイム計測）
- 手数カウンタ
- ヒント機能（段階的に詳しくなる）
- 持ち物欄、リスタート
- クリア画面：桜吹雪＋成績表示（タイム／手数／ヒント使用回数）
